# Architecture Decision Records

Northstar uses Architecture Decision Records (ADRs) to capture decisions that materially shape the product's technical design.

| ADR | Decision | Status |
| --- | --- | --- |
| [ADR-001](001-quote-versioning.md) | Version quotes as immutable commercial decisions | Accepted |
| [ADR-002](002-budget-fit-optimization.md) | Implement Budget Fit as constrained configuration search above the pricing engine | Accepted |

ADRs document **why** a choice was made, alternatives considered, and the consequences the implementation should preserve. They are intentionally separate from `ARCHITECTURE.md`, which describes the current target architecture as a whole.
